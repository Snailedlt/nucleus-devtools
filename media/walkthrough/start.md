# Start a handler

Two ways in, both ending in the same plain handler code:

- **New Handler…** asks for the game's name, its .exe and the features you want, step by step, and saves `<Name>.js` with its `<Name>/` folder in the folder you pick.
- **Browse the Hub…** opens a handler that already works for a similar game (same engine, same launcher), to learn from or start from.

In an empty `.js` file, typing `handler` offers the whole template too.
