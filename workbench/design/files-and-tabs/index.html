    What is different from today

    • The file list is the outer level. Each open handler is a folder named after its game, laid out like its Hub package: handler.js first, then the other files. Today the tabs are whole handlers and Files lists what's inside one.
    • Tabs are open files. Click a file in the list to open it, the × to close its tab. Closing a tab doesn't close the handler: it stays in the list.
    • The rail switches the side panel, Files or Lines, and the same button hides it. Save and Share move to the right of the tabs.
    • Check, Try it and Docs follow the handler of the open file, also when that file is its config.ini. A tab names the game beside the file, since every handler's code is a handler.js.
