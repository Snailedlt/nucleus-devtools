Make a handler with AI

Set up your AI for Nucleus Co-op handlers

AI can write a handler, but it guesses option names and uses JavaScript Nucleus can't run. Our tools give it the real Nucleus API and the same checks and Try it as the workbench, so what it writes loads and works.

  • Free: VS Code with GitHub Copilot's free plan and our extension (it adds the tools for Copilot itself), or any free chatbot with the workbench to check its code.
  • Paid: Claude Code with our plugin, or any other coding agent. Both set themselves up with the setup prompt below.

Pick your AI, copy, paste

1. Set up (once)

Install the Nucleus Co-op plugin for me:
1. Run: claude plugin marketplace add __CLAUDE_MARKETPLACE__
2. Run: claude plugin install __CLAUDE_PLUGIN__
3. Tell me to restart Claude Code.

The plugin brings the guide (a skill) and the tools (an MCP server). Needs Node.js 18 or newer.

2. Make a handler (once per game, in a new chat)

Make a Nucleus Co-op handler for <name>.

Use the nucleus-handler skill. Look up every option with nucleus_api instead of guessing, run nucleus_lint after every edit, and nucleus_simulate with 2 and 4 players before you give me the handler. If you don't have the nucleus tools, stop and tell me to do the setup at https://snailedlt.github.io/nucleus-devtools/ai/ first.

Ask me what you need to know about the game (engine, .exe name, how multiplayer works, where it keeps settings and saves). Ask for a link to its store or wiki page, and for the path to its install folder so you can look at its files (nucleus_game_imports shows what it uses for controllers, input and windows), if that would help.

One game per chat: for three games, start three new chats.

Make a handler (once per game, in a new chat)

Help me write a Nucleus Co-op handler for <name>. A handler is the JavaScript file Nucleus Co-op (SplitScreen.Me) uses to run several copies of a PC game split-screen, one per player. Follow these rules exactly:

__AI_HARD_RULES__

Game.Play runs once per player: use Context.PlayerID (0-based), Context.Width and Context.Height, and set Context.StartArguments there.

When you give me a handler, tell me to paste it into https://snailedlt.github.io/nucleus-devtools/ to check it; I'll send you the problems it finds. Then fix only those, and give me the whole file.

Ask me what you need to know about the game. Ask for a link to its store or wiki page, or for the list of files and folders in its install folder, if that would help.

No setup. For ChatGPT, Claude, Gemini, Grok, Copilot Chat and other chatbots. Paste their handler into the workbench, send back what Check finds, and Try it before testing in Nucleus.
