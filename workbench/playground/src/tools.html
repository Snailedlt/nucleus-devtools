Get the tools

One engine, wherever you write handlers

The same checks, docs, suggestions and Try it in each of them, so pick where you already work. You can use more than one: a handler checked in one is checked the same in the others.

  • WorkbenchIn your browser. Nothing to install; also the debugger.Open it
  • VS CodeRecommended. An extension, also for VSCodium, with the most to show.Download and set up
  • Notepad++A plugin, installed by one small program.Download and set up
  • Other editorsNeovim, Helix, Sublime Text, Emacs, Kate, JetBrains, Zed: through a language server.Set up your editor
  • >_Command linencdev: check, fix, format and test handlers, one at a time or a whole folder.Download and install
  • ✦AIClaude Code, Codex, Cursor, ChatGPT and others write handlers that load, checked by the same engine.Set up your AI

Which one?

If you just want to try it, open the workbench: there's nothing to install. For an editor, we recommend VS Code, which shows the most (hovers with docs, a Docs panel, Try it, a debugger). Notepad++ has every feature too, in a plainer way, and other editors get them through a language server.

What each tool can do, feature by feature, is in the docs, along with what each tool is. New to handlers? Learn builds a first one with you.

Using an editor nobody has tested yet, or one that's missing? Vote in the editor poll on Discord (join the server first if you're new). It decides which editors get tested next.

Beta. It checks the handler script, not the game: windows, focus and input still need a real test in Nucleus. Nothing on your computer changes until you press Install or Test in Nucleus.
